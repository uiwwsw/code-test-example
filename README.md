간단한 가입, 로그인 벨리데이션 처리
과제: 외부 package없이 폼, 벨리데이션 구현하기

리소스: 1d(오전11~오후11)

## 로컬 실행

Next.js 13, React 18, TypeScript 기반 프로젝트입니다. 저장소의 `pnpm-lock.yaml`을 기준으로 의존성을 설치합니다.

```bash
pnpm install
pnpm dev
```

개발 서버는 기본적으로 http://localhost:3000 에서 확인할 수 있습니다.

- `pnpm build`: 프로덕션 빌드
- `pnpm start`: 빌드 결과 실행 (`pnpm build` 이후)
- `pnpm lint`: 린트 검사

코드 위치: `app/`, `components/`, `template/`, `utils/`.
